\## Зорилго

Push болон Pull Request үүсэхэд тестүүдийг автоматаар ажиллуулж,

амжилттай болон амжилтгүй үр дүнг шалгав.



\## Тохиргоо

\- Workflow: `.github/workflows/ci.yml`

\- Trigger: `push`, `pull\_request`

\- Орчин: Ubuntu, Python 3.12

\- Хамаарал: `lab7/requirements.txt`

\- Тестийн команд: `python -m pytest lab6/tests -v`



\## CI-ийн дөрвөн алхам

1\. Checkout — repository-ийн кодыг татна.

2\. Setup Python — Python 3.12 орчныг бэлдэнэ.

3\. Install dependencies — pytest суулгана.

4\. Run tests — 18 тестийг ажиллуулна.
