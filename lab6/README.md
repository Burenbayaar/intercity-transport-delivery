## Зорилго

Хоёр хүн тус тусдаа feature branch үүсгэж, нэг функцийн ижил мөрийг өөр өөрөөр өөрчлөнө. Хоёр PR үүсгэж, харилцан PR бүрд дор хаяж хоёр бодитой санал өгнө. Эхний PR-ийг merge хийсний дараа хоёр дахь branch дээр үүсэх conflict-ийг хоёр дүрмийг хадгалж шийдвэрлэн, тестэлж, хоёр дахь PR-ийг main руу merge хийнэ.

## Энэ багцын төлөв

Энэ нь бодит GitHub дасгалыг гүйцэтгэх **бэлэн эх ба заавар** юм. Багц бэлдсэн нь хоёр хүний PR, review, remote merge дууссан гэсэн үг биш. `evidence/report.md`-д бодит commit SHA болон PR/comment холбоосоо нэмсний дараа нотолгоо бүрдэнэ.

`booking.py` нь зориуд дутуу үлдээсэн сургалтын суурь функц. Тэг/сөрөг суудлын тоо болон хаалттай аяллын шалгалтыг хоёр тусдаа feature дээр гүйцээнэ. Бодит захиалга хадгалахгүй, суудал нөөцлөхгүй; зэрэгцээ захиалгыг хамгаалахгүй. Жинхэнэ системд шалгалт, нөөцлөлтийг өгөгдлийн сангийн нэг гүйлгээнд хийнэ.

## Хоёр feature

| Branch | Нэмэх дүрэм | Үндсэн файл | Шинэ тест |
|---|---|---|---|
| `feature/seat-validation` | Захиалах суудлын тоо 0-ээс их, сул суудлаас хэтрэхгүй байна. | `lab6/booking.py` | `test_seat_validation.py` |
| `feature/trip-status` | Зөвхөн `OPEN` төлөвтэй аялал захиалга авна. | `lab6/booking.py` | `test_trip_status.py` |

Нийтлэг дүрэм: суудлын тоонууд бүхэл тоо байна; `bool`, бутархай, текстийг зөвшөөрөхгүй. Сул суудлын тоо сөрөг байж болохгүй.

## Шалгах команд

Репозиторийн үндсэн хавтсаас:

```powershell
python -m unittest discover -s lab6/tests -v
git diff --check
```

Зөв дарааллаар явбал: суурь 5 тест, A feature 10 тест, B feature 9 тест, хоёр feature ба нийлмэл шалгалтууд нэгдсэний дараа 18 тест амжилттай байна. `variants/` дахь тестүүдийг зааврын дагуу `tests/` рүү хуулах хүртэл үндсэн тестийн багцад оруулахгүй.

## GitHub дээр дууссаны дараа тэмдэглэх шалгуур

- [ ] Хоёр өөр хүн хоёр feature branch дээр commit хийсэн.
- [ ] Хоёр PR main руу чиглэн нээгдсэн.
- [ ] Эхний PR дээр нөгөө хүн дор хаяж 2 бодитой review comment бичсэн.
- [ ] Эхний PR main руу merge болсон.
- [ ] Хоёр дахь branch дээр conflict бодитоор үүссэн.
- [ ] Conflict-ийн зураг/тэмдэглэл, шийдлийн commit бүртгэгдсэн.
- [ ] Хоёр дүрэм хадгалагдаж, 18 тест амжилттай болсон.
- [ ] Хоёр дахь PR дээр нөгөө хүн дор хаяж 2 бодитой review comment бичсэн.
- [ ] Хоёр дахь PR main руу merge болсон.
- [ ] Тайланд жинхэнэ commit, PR, review comment-ийн холбоосууд орсон.
